#JAVA CONSOLE CALCULATOR

DESCRIPTION: 

This project is a console-based application designed to bridge the gap between mathematical logic and algorithmic implementation. It allows users to perform basic arithmetic operations by entering two numbers and selecting an operator (+, −, ×, ÷). By utilizing conditional logic and switch statements, the program efficiently determines the required operation while maintaining high precision. A key feature of this project is its robust error-handling mechanism, which prevents common mathematical errors such as division by zero, ensuring the system remains stable and reliable under all input conditions.

TOOLS USED:

1) Java
2) Java Scanner: For precise user input capture.
3) Control Structures: switch statements and conditional logic.
4) Error Management: Custom logic for handling undefined mathematical cases.
